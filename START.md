# Запуск за 10 минут

Токен уже вписан в файл `.env`. Он в `.gitignore`, поэтому на GitHub не попадёт.

---

## Шаг 1. Проверить бота на своём компьютере (3 минуты)

**Windows:** распакуйте папку и дважды кликните **`start.bat`**.
Скрипт сам создаст окружение, поставит библиотеки и запустит бота.

**Mac / Linux:** в терминале `./start.sh`

Пока окно открыто — бот работает. Откройте своего бота в Telegram и напишите `/start`.
Проверьте: выбор языка → раздел «Хадис» → откройте книгу → скачайте PDF.

Если Python не установлен — https://www.python.org/downloads/, при установке обязательно
отметьте **Add python.exe to PATH**.

---

## Шаг 2. Выложить проект на GitHub (3 минуты)

1. https://github.com/new → имя `kitob-bot` → **Create repository**.
2. Загрузите файлы: кнопка **uploading an existing file** → перетащите содержимое папки.
   Файл `.env` загружать не нужно — токен должен остаться только у вас.
3. **Settings → Pages → Source: GitHub Actions.** Через минуту мини-приложение будет
   доступно по адресу `https://ВАШ-ЛОГИН.github.io/kitob-bot/`.

---

## Шаг 3. Подключить мини-приложение к боту (1 минута)

1. Впишите адрес из шага 2 в `.env`:
   `WEBAPP_URL=https://ВАШ-ЛОГИН.github.io/kitob-bot/`
2. Перезапустите бота — в меню появится кнопка «📱 Приложение».
3. В @BotFather: `/mybots` → ваш бот → **Bot Settings → Menu Button → Edit menu button URL** →
   вставьте тот же адрес. Тогда приложение открывается кнопкой рядом с полем ввода.

---

## Шаг 4. Чтобы бот работал без вашего компьютера

Выберите **один** вариант.

### Вариант A — Render (рекомендую, файл `render.yaml` уже готов)

1. https://render.com → войти через GitHub.
2. **New → Blueprint** → выберите репозиторий `kitob-bot`.
3. Render найдёт `render.yaml` и попросит ввести переменные:
   - `BOT_TOKEN` — токен бота
   - `WEBAPP_URL` — адрес GitHub Pages
4. **Apply.** Через 3–4 минуты бот работает круглосуточно.

### Вариант B — только GitHub, без сторонних сервисов

1. В репозитории: **Settings → Secrets and variables → Actions**
   - вкладка **Secrets** → New secret → имя `BOT_TOKEN`, значение — токен
   - вкладка **Variables** → New variable → имя `WEBAPP_URL`, значение — адрес Pages
2. **Actions → Run bot (fallback) → Run workflow.**

Бот будет жить внутри GitHub Actions и перезапускаться каждые 5 часов.
Минус: при перезапуске 1–2 минуты бот не отвечает. Для теста годится, для постоянной
работы лучше вариант A.

## Про безопасность токена

Токен вы прислали в переписке, а это всё равно что пароль от бота: любой, у кого он есть,
может писать от имени вашего бота. Когда закончите настройку, сделайте так:

1. @BotFather → `/mybots` → ваш бот → **API Token → Revoke current token**.
2. Новый токен вставьте в `.env` (и в переменные Render / GitHub Secrets, если используете).

Старый токен сразу перестанет работать — переписка уже не будет иметь значения.
